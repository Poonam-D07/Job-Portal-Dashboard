# 💼 Job Portal Dashboard

A modern and responsive Job Portal Dashboard built using **HTML, CSS, and JavaScript**. The project simulates a real-world job portal where candidates can search jobs, save jobs, apply for jobs, manage applications, and track their profile — all without a backend.

---

## 🚀 Features

- Responsive Dashboard
- Find Jobs
- Search Jobs
- Filter by Location
- Filter by Experience
- Filter by Job Type
- Filter by Salary
- Sort Jobs
- Job Details Modal
- Bookmark / Save Jobs
- Apply for Jobs
- My Applications
- Notifications
- Candidate Profile
- Settings
- Dark / Light Theme
- LocalStorage Persistence
- Loading Skeleton
- Toast Notifications
- Pagination
- Smooth Animations
- Responsive Design
